05 / World Forge - In development

A world built for
true freedom.

World Forge is my vision for a single-player role-playing game where the world responds to what the player actually does.

The setting and its rules already exist. Within them, choices can open new paths instead of forcing every story back onto two scripted dialogue options.

It is a massive project and far from finished. The public description stays high-level while the underlying ideas and implementation continue to develop.
